# Quiz App Specification

**Project:** Gabby's Quiz Website
**Repo:** gabbym12/Quizwebsite
**Built with:** HTML, CSS, and JavaScript — developed 100% in Mistral 💜
**Workflow:** All work happens on the `feature/quiz-app-specification` branch. Never work on `main` directly.

---

## 🎯 Goal

A fun, polished trivia quiz website with multiple questions, instant feedback, a score tracker, and a results screen.

## 🧑‍💻 Target user

Anyone who wants a quick, fun trivia break — friends, family, classmates.

## ✅ Requirements

1. Home screen with a title and a "Start Quiz" button
2. At least 6 trivia questions with 4 answer options each
3. Instant feedback: correct answer lights up green, wrong picks turn red
4. Live score counter and progress bar during the quiz
5. Results screen with final score and a fun message
6. Works on desktop and mobile
7. Looks good: themed, colorful, playful

## 🚫 Non-goals (for now)

- User accounts / login
- Saving scores to a database
- Multiplayer
